# 실시간 번역 자막

웹 페이지에서 재생 중인 영상 위에 번역 자막을 띄우는 크롬 확장 프로그램입니다. 영상에 들어 있는 자막을 재생 시각에 맞춰 읽고, 고른 언어로 번역해 화면 하단에 표시합니다.

## 설치

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension` 폴더를 선택합니다.
4. 자막이 있는 영상을 재생합니다. 유튜브와 `<track>` 자막이 있는 일반 영상에서 동작합니다.

번역 언어, 원문 표시, 글자 크기는 확장 프로그램 아이콘에서 바꿉니다. 자막이 없는 영상은 번역할 문장이 없어 표시하지 않습니다. 자막 문장만 Google 번역으로 전송되며 음성은 전송되지 않습니다.
